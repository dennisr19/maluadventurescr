# Malú Adventures

Sitio oficial de **Malú Adventures**, operador de tours y experiencias en la costa del Pacífico de Costa Rica.

La página permite descubrir, comparar y solicitar aventuras directamente por WhatsApp. Está disponible en español e inglés y presenta precios, horarios de salida y fotografías de cada experiencia.

## Sobre Malú Adventures

Malú Adventures conecta a viajeros con experiencias de naturaleza, océano y aventura en Costa Rica. El catálogo incluye 23 opciones entre parques nacionales, manglares, playas, cataratas, ríos y actividades en el Pacífico.

Entre los tours más solicitados se encuentran:

- Parque Nacional Manuel Antonio
- Tour de manglar en bote o kayak
- Moto acuática

También se ofrecen caminatas nocturnas, canopy, ATV, paseos a caballo, rafting, catamarán, pesca, snorkeling, kayak, parasailing, transporte privado y otras experiencias.

## Iniciar el proyecto

Necesitas tener instalados [Node.js](https://nodejs.org/) y npm.

```bash
npm install
npm run dev
```

El sitio estará disponible en `http://localhost:4321`.

Para comprobar y generar la versión final:

```bash
npm run check:full
```

Para desplegar el proyecto en Cloudflare:

```bash
npm run deploy
```
